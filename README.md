# GibCoins

GibCoins is a light weight addon for Hypixel Skyblock, mainly intended for having fun in your parties and adding some small qol features. The mod adds a hand full of party commands (!<command> in party chat), thatll allow new funny moments with your friends. Use /gchelp for a full list of commands.

/coin opens the mods config gui, which lets you toggle all the qol features. Currently the qol includes:

- a Player Hider with a lot of customization options
- InvMeow (Plays a cat sound whenever you proc your invincibility)
- Schizophrenia
Im actively working on more features. Feel free to contact me, if you want to request a feature.
