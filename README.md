# GibCoins

GibCoins is a lightweight addon for Hypixel Skyblock, mainly intended for having fun in your parties and adding some small qol features. The mod adds a handful of party commands (!<command> in party chat), that'll allow new funny moments with your friends. Use /gchelp for a full list of commands.

/coin opens the mods config gui, which lets you toggle all the features. Currently included are:

- a Player Hider with a lot of customization options
- Diana qol (Easy toggle to deal with annoying hitboxes in the Diana event)
- InvMeow (Plays a cat sound whenever you proc your invincibility)
- Schizophrenia
- Player Size

I'm actively working on more features. Feel free to contact me, if you want to request a feature.
